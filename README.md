---

## 📋 Descripción

Este repositorio reúne **todo el trabajo realizado durante la cursada de Programación II (2.º cuatrimestre 2026)**, ordenado de forma cronológica: desde las primeras clases de Programación Orientada a Objetos hasta los proyectos finales de la materia.

Cada carpeta corresponde a una clase o práctica y contiene su propio código fuente en **C++**. Está pensado como:

- 📚 **Material de estudio** para repasar cada tema en orden.
- 🧪 **Registro de práctica** con ejercicios resueltos y proyectos propios.
- 🗂️ **Portfolio académico** que muestra la evolución a lo largo de la cursada.

## 🚀 Requisitos

- **Compilador:** `g++` con soporte para C++11 o superior (MinGW / MSYS2 en Windows, `build-essential` en Linux).
- **Sistema operativo:** Windows, Linux o WSL2.
- **Editor recomendado:** Visual Studio Code, Code::Blocks o Visual Studio.
- **Git** para clonar el repositorio.

---

## 📥 Cómo usarlo

### 1. Clonar el repositorio

```
git clone https://github.com/EliasTiki951/Programming-II-2C-2026.git
cd Programming-II-2C-2026
```

### 2. Entrar a la práctica que quieras probar

```
cd "17- Tienda 1"
```

### 3. Compilar y ejecutar

```
# Compilar todos los archivos .cpp de la carpeta
g++ -std=c++11 *.cpp -o programa

# Ejecutar
./programa          # Linux / WSL2
programa.exe        # Windows
```

> 💡 Cada carpeta es independiente: podés compilar y probar cada práctica por separado.

## 🎯 Objetivos de aprendizaje

- Comprender y aplicar los pilares de la **Programación Orientada a Objetos**.
- Administrar la **memoria de forma manual** y evitar fugas de memoria.
- Dominar el uso de **punteros, dobles punteros y arreglos dinámicos**.
- Persistir información mediante **archivos**.
- Organizar el código en **funciones y clases reutilizables**.
- Integrar todo lo aprendido en **proyectos completos**.
